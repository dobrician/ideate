# Landing Page Feedback (Claude Code Review, 2026-02-16)

## Summary
The current landing page is functional but not conversion-optimized. It reads like an app dashboard, not a product page.

## Issues Identified

### 1. Hero is too generic
- Current: "Welcome to Ideate" + "Democratic idea prioritization for teams"
- Problem: Doesn't tell visitors why they should care
- Fix: Benefit-driven headline, e.g. "Lasă echipa să decidă ce contează"

### 2. CTAs don't make sense for new visitors
- Current: "View Projects" and "Dashboard" — these are for logged-in users
- Fix: "Încearcă gratis" / "Creează primul proiect" + "Vezi un demo"

### 3. Feature grid is flat
- Lists features but doesn't explain benefits
- Each card needs: Title + Benefit (not just description) + visual

### 4. Missing critical sections
- How it works (3 steps)
- Social proof (even "Used by 3 teams internally")
- Screenshot / demo visual
- Pricing / final CTA
- Proper footer with links, contact, legal

### 5. "Enterprise-grade" is premature
- Sets expectations (SSO, SOC2, SLA) that aren't met yet
- Use "built for teams" or "for teams that ship" instead

### 6. Navigation isn't visitor-friendly
- Current: EN | Profile | Theme toggle
- Should be: Logo | Features | How it works | Pricing | Login | **Sign Up** (highlighted)

## Ideal Landing Page Structure
1. Hero — headline + CTA + product screenshot
2. Social proof bar — logos or a stat
3. How it works — 3 simple steps
4. Features — with benefits, not just descriptions
5. Screenshot / demo
6. Testimonial or quote
7. Final CTA + pricing
8. Footer

## Priority
This should be part of Sprint 10 (UI/UX polish).
